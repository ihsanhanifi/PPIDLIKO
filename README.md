# PPID Kemenag Kab. Lima Puluh Kota

Aplikasi web Pejabat Pengelola Informasi dan Dokumentasi (PPID) untuk Kantor Kementerian Agama Kabupaten Lima Puluh Kota.

## 🚀 Fitur

- ✅ Halaman Publik dengan informasi lengkap
- ✅ Form Permohonan Informasi Online
- ✅ Form Keberatan Informasi Online
- ✅ Dashboard Admin dengan statistik real-time
- ✅ Upload file ke Google Drive (PDF, Image, DOC, XLS)
- ✅ Tampilan image di halaman publik
- ✅ Download file dari halaman publik
- ✅ Manajemen Dokumen (CRUD)
- ✅ Manajemen Permohonan & Keberatan
- ✅ Edit Profil PPID oleh Admin
- ✅ Autentikasi Admin (1 admin utama)
- ✅ Responsive Design (Mobile & Desktop)
- ✅ Database Google Spreadsheet
- ✅ File Storage Google Drive
